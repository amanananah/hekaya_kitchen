## Working agreement

- Use small commits that describe one meaningful change.
- Open issues for defects and link fixes back to them.
- Review privacy, safety, cultural interpretation, and AI-boundary changes with a second member.
- Never commit passwords, API keys, signing credentials, private recordings, or real family data.
