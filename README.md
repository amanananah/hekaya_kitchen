# Mirath · ميراث

Mirath is a mobile-first family heritage app that helps elders pass down the unwritten knowledge behind traditional recipes. It turns natural cooking demonstrations into visual checkpoints, family stories, and a guided learning experience for the next generation.

## Product promise

> Preserve more than ingredients. Pass down the instinct.

## Current milestone

- Installable, dependency-free web prototype
- Mobile-first application shell
- Sample family recipe journey
- Capture and Grandchild Mode demo flows

## Run locally

Serve this folder with any static web server. For example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.
